## 2024-05-18 - [O(N^2) Frontend Dashboard Loop Optimization]
**Learning:** In timeline dashboards and streak trackers (`renderStreaks` and `renderTopBarStats`), validating completed elements against active routine lists dynamically inside retroactive loop checks creates massive performance degradation (`O(Days * CompletionsPerDay * TotalRoutines)`). `state.routines.some()` causes deep iterations inside high-frequency renders. Furthermore, sorting routines dynamically without caching heavy dependency calculations like `calculateStreak` creates `O(N log N)` overhead.
**Action:** When evaluating retroactive global streaks or rendering multi-day grids over a state log, always extract arrays into `Set` structures (`const routineIds = new Set(routines.map(r => r.id))`) for `O(1)` validation before iterating the dataset. Additionally, calculate heavy metadata (like streak math) prior to sorting logic to leverage `Map` caching.
